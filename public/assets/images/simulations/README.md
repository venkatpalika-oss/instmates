# Simulation visual assets

All SVGs in this directory are original, code-authored generic illustrations
created for InstMates in this local visual-enhancement slice. No third-party
photography, vendor artwork, fonts, scripts, raster embeds or external URLs.
The approved dashboard concept informed layout, not equipment branding or
technical fault claims. InstMates branding identifies the learning website,
not the depicted manufacturer.

Equipment assets use a shared 160 × 180 viewBox. UI text and live values are
HTML overlays rather than baked into assets. The process vessel has no liquid
fill: a separate moving gauge indicates normalized process position, not a
hydrostatic relationship. Icons use a 48 × 48 viewBox and a consistent stroke.
SVGs contain only vector geometry and a local metallic gradient.

Files: process-vessel.svg, smart-transmitter.svg, analog-input-rack.svg,
engineering-display.svg; icon-*.svg cover the 13 technical topics.
